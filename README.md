# Raid Helper 0.2.0-beta.7 — бета

WoW 3.3.5a: разбор рейда по боевому логу (сводки, таймлайн, реплей, гпшница) и сбор состава. Окно — `/mrh`.
Это бета: об ошибках — в Discord.

**Установка.** Закрыть игру, распаковать архив в `Interface\AddOns`, запустить игру. Старую папку
`HTP_FailWatch` и файл `HTP_FailWatch.lua` в `SavedVariables` удалить — запись не переносится.

**Обновлялка** `RaidHelperUpdate.exe` — запустить из папки `Interface\AddOns\ManaCode_RaidHelper`: `G` — обновить, `B` — бета-версии,
`T` — автообновление, `D` — тестовая запись ([ветка data](https://github.com/dmitriinosach/-MANACODE-RaidHelper/tree/data)). Защитник Windows может ругаться на неподписанный exe — разрешите файл.

**3D-залы реплея** — отдельными архивами по рейдам: `ManaCode_RaidHelper_ICC-v0.2.0-beta.7.zip` (ЦЛК).
Распаковать туда же, в `Interface\AddOns`, версия — как у аддона; без пакета реплей рисует плоский пол. Обновлялка ставит пакеты по отметкам «3D-залы».

С тестовой записью аддон рейды не пишет; вернуть запись — Настройки → «Обслуживание» →
«Выйти из тестовой записи».
