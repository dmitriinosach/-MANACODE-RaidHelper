# Тестовые записи Raid Helper

Наборы записи для проверки аддона без своих рейдов. Ставит обновлялка боберлога (`ОбновитьДанные.exe`), клавиша `D`: выбрать аккаунт и набор, игра должна быть закрыта; своя запись сохраняется копией, `R` — вернуть.

Вручную: открыть `rec/<набор>.zip` в 7-Zip или WinRAR паролем `raids-circle` и положить `ManaCode_RaidHelper.lua` в `WTF\Account\<аккаунт>\SavedVariables` (свою запись сохраните заранее).
